# 📥 Download Pixiv Token Getter

**Language / 语言:** [中文](/docs/download.md) · English

This package is **distributed only through npm** — there is no standalone binary or
per-platform installer. See [Releases](https://github.com/redtidev1918/pixiv-token-getter/releases)
for version history and release metadata.

## Install as a dependency

```bash
npm install pixiv-token-getter
```

## Install the CLI

The package exposes two equivalent command names (`pixiv-token-getter` and `ptg`):

```bash
npm install -g pixiv-token-getter
ptg --help
```

## Run from source

```bash
git clone https://github.com/redtidev1918/pixiv-token-getter.git
cd pixiv-token-getter
npm ci
node cli.js --help
```
