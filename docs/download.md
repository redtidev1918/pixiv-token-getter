# 📥 下载 Pixiv Token Getter

**语言 / Language:** 中文 · [English](/docs/en/download.md)

本包**只通过 npm 分发**，没有独立二进制或平台安装包。版本记录与发版元数据见 [Releases](https://github.com/redtidev1918/pixiv-token-getter/releases)。

## 作为依赖安装

```bash
npm install pixiv-token-getter
```

## 作为 CLI 安装

包内提供两个等价的命令名（`pixiv-token-getter` 与 `ptg`）：

```bash
npm install -g pixiv-token-getter
ptg --help
```

## 从源码运行

```bash
git clone https://github.com/redtidev1918/pixiv-token-getter.git
cd pixiv-token-getter
npm ci
node cli.js --help
```
